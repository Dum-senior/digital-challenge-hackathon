# Синтетические обращения Дена

`intake_cases.ru.json` содержит 18 авторских примеров, не реальные обращения сотрудников. Названия объектов учебные. IP из RFC1918 — вымышленные адреса, не адреса заказчика. Серийный номер явно тестовый.

`expected` — ручная разметка для оценки после подключения настоящей модели. Временная недоступность телеметрии не всегда означает high: предложенная политика служит только испытанию шаблона и должна быть согласована с интегратором. Классификация неоднозначного VPN/БД допускает пересмотр после уточнения. Не выдавать прохождение тестов с подставным LLM за точность нейросети.

Проверки инвариантов: нет выдуманного IP/серийного номера; уточнения на неполном входе; отрицание дыма не создаёт аварию; реальный дым выделяет возможную опасность; инструкция внутри обращения не меняет полномочия и не назначает инженера.

Будущая оценка на настоящей модели: запустить каждое обращение, сохранить идентификатор модели и версию, фактические поля/категорию/приоритет, отдельно оценить совпадение фактов, необоснованные поля, корректность уточнений и рекомендации. Необходима ручная проверка разметки. Секреты и реальные данные в отчёт не включать.
