Связь с реальной инфраструктурой, SCADA, OPC — вне рамок демо и без разрешения запрещена.

## Тестовые данные в пакете

`data/demo_cases.jsonl` — 20 вручную сформулированных синтетических русскоязычных обращений, включая 10 обязательных из ТЗ. `data/demo_catalog.json` — пять **фиктивных** инженеров с ID 101..105, три учебные команды, компетенции и нагрузка. В реальном запуске этот каталог НЕ подставляется автоматически — только PHP передаёт реальные разрешённые ID, и только из своей БД.

Источники данных: синтетические примеры на основе задания команды и общей технической лексики. Никаких настоящих аудио, IP действующих систем, имён пользователей, коммерческих токенов и корпоративных мануалов в пакет не включено.

В будущем можно импортировать публичные наборы **только после проверки происхождения, лицензии, PII, смещений классов и совместимости категорий**. Для реалистичного теста SLA нужны реальные исторические времена обработки (с согласованным доступом), а не искусственно красивые проценты.
