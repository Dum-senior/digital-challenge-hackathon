# TEST_RESULTS.md — 2026-11-14, локальный прототип 02_ДЕН

Среда: CPython 3.13.5, pytest 9.0.2, FastAPI 0.128.2, Pydantic 2.13.5, httpx 0.28.1. Установленные зависимости предварительно присутствовали в изолированной среде тестирования. Проверка: `PYTHONPATH=. pytest -q` из `services/intake-ai`.

Результат: **34 passed, 0 failed**.

Охвачены: обязательные 10 кейсов из ТЗ; отдельное извлечение НТП/времени/IP; запрет выдумывания; «Принтер дымит»; уточнение; выбор по навыкам/загрузке/доступности; неподтверждённый инженер; invalid ID/source; три варианта канала; риски SLA; вход без токена; большой body; небезопасный LLM endpoint; отсутствие ключа; отказ провайдера; невозможность понизить приоритет опасного обращения моделью.

**Не выполнено**: интеграционный запуск OpenHelpDesk PHP/MySQL, сохранение реального черновика и подтверждение диспетчером, реальная модель Qwen3/vLLM, latency/accuracy benchmark на GPU, реальные роли/права, нагрузочное и penetration тестирование, настоящая телефония/Whisper. Функции этих направлений принадлежат команде и должны быть проверены после merge.

`uv lock --offline` не выполнен: индекса PyPI и cached wheel/metdata `fastapi` в среде нет. `uv lock` с сетевым доступом также не завершился из-за таймаута PyPI. Поэтому `uv.lock` **не подделывается** и должен быть создан на машине с разрешённым доступом: `uv lock && uv sync --locked --group dev && uv run pytest -q`.

Выкладка в GitHub не выполнена: ветку `хуй` создал пользователь, но запись файла и Git Tree через подключённый GitHub по-прежнему возвращают `403 Resource not accessible by integration`, несмотря на reported `push=true`. В текущей среде прямой git push невозможен из-за сетевого ограничения. Это блокер доступа, не тестов кода. `main` не изменялся.
