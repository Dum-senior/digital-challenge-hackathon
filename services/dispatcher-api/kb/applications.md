# Приложения

## Сервис возвращает HTTP 503

**Признаки.** Внутренний веб-сервис отвечает Service Unavailable нескольким пользователям.

**Проверки.** Записать время, адрес и затронутые операции; проверить повторяемость на другом рабочем месте.

**Решение и эскалация.** Передать владельцу сервиса код ошибки и данные для проверки доступности.

## В браузере ошибка сертификата

**Признаки.** ERR_CERT_DATE_INVALID или сообщение о недоверенном сертификате.

**Проверки.** Проверить дату и время устройства и точный домен; сравнить с другим корпоративным устройством.

**Решение и эскалация.** Передать владельцу сервиса ошибку и сведения о сертификате. Открывать сайт в обход предупреждения не следует.

## Форма не сохраняет запись

**Признаки.** Ошибка возникает при сохранении, остальные разделы работают.

**Проверки.** Записать обязательные поля без персональных данных, время и текст ошибки.

**Решение и эскалация.** Проверить допустимые форматы полей. Передать разработчикам воспроизводимый пример с синтетическими данными.

## Отчёт показывает устаревшие цифры

**Признаки.** Оперативная панель и экспорт за тот же период расходятся.

**Проверки.** Сравнить часовой пояс, период, время обновления и фильтры.

**Решение и эскалация.** Передать владельцу отчётности параметры и ожидаемый момент обновления выгрузки.

## HTTP 403 после обновления портала

**Признаки.** Сервис доступен, запрет возникает у пользователей определённой роли.

**Проверки.** Сравнить две роли, точный маршрут и время начала относительно выпуска.

**Решение и эскалация.** Передать владельцу портала шаги воспроизведения и перечень затронутых ролей.

## HTTP 502 при вызове отдельной функции

**Признаки.** Главная открывается, операция через интеграцию возвращает Bad Gateway.

**Проверки.** Зафиксировать точное действие, время и идентификатор запроса, если показан.

**Решение и эскалация.** Передать владельцу приложения для проверки зависимой службы. Избегать повторной отправки операции с побочным эффектом.

## Дубли после повторного нажатия сохранить

**Признаки.** Две записи появились после долгого ожидания или обновления страницы.

**Проверки.** Сверить идентификаторы, время и исходную операцию, проверить итог до повторной отправки.

**Решение и эскалация.** Передать владельцу процесса обе записи и согласовать, какую сохранить.

## Экспорт завершается ошибкой только на большом периоде

**Признаки.** Сутки выгружаются, квартал завершается таймаутом.

**Проверки.** Зафиксировать тип отчёта, интервал, фильтры и объём успешной выгрузки.

**Решение и эскалация.** Использовать меньшие периоды, если это допускает процесс. Передать владельцу отчётности границу воспроизведения.

## Уведомление пришло, карточка не открывается

**Признаки.** Сообщение доставлено, переход по ссылке даёт ошибку или запрет.

**Проверки.** Сверить идентификатор заявки, получателя и текущую роль. Найти заявку через обычный поиск.

**Решение и эскалация.** Передать владельцу уведомлений адрес без токенов и тип ошибки. Права уточнить с диспетчером.
