# 02_ДЕН — ИИ-диспетчер (командный модуль)

Командный репозиторий: https://github.com/Dum-senior/digital-challenge-hackathon
**Целевая ветка пользователя:** `хуй` (создана владельцем, не менять `main`).

## Готово и проверено

Самостоятельный `services/intake-ai/` принимает русскоязычный текст, транскрипцию голоса/телефонии, классифицирует безопасными правилами, извлекает известные поля, предлагает кандидата-инженера **только из переданного сервером** каталога и возвращает структурированное предложение. Запуск с локальной OpenAI-совместимой LLM предусмотрен, но не подтверждён на GPU. Проведены 34/34 локальных теста и HTTP smoke-test (аварийный случай -> `critical`, HTTP 200).

Сервис не создаёт конечные заявки, не назначает исполнителей, не хранит аудио, не изменяет чужие директории. Для полноценной работы продукта необходим отдельный PHP-адаптер команды: текущая авторизация пользователя, сохранение настоящего черновика, подтверждение диспетчером и журнал. Подробно в `services/intake-ai/docs/INTEGRATION.md`.

## Отправка в ветку без Codex

Если у ChatGPT GitHub-интеграции нет права `Contents: Read and write`, безопасно запустите на **своём** компьютере входящий в пакет `publish_02_den.sh`. Он **только** клонирует конкретную ветку `хуй`, применяет патч и делает обычный `git push` через уже настроенный GitHub-доступ вашего компьютера, без `--force` и без изменения `main`. Скрипт можно предварительно открыть и проверить. Не передавайте персональный токен/пароль в чат.

Если есть рабочая копия репозитория, альтернативно используйте `git switch хуй`, `git am 02_DEN_dispatcher_ai.patch`, `git push origin хуй` после предварительной проверки чистоты рабочего дерева. При конфликтах не применяйте патч поверх чужих изменений силой.

Соседние компоненты: `feature/voice-ai` — Ваня, `feature/engineer-ai` — интегратор, тесты/телефония — Кирюха. Полный OpenHelpDesk ещё не был импортирован в `main` на момент проверки, поэтому сервис изолирован и не заменяет штатную PHP-систему.
